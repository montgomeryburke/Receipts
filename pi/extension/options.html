Pi NAS

Connect this extension to the file server on your Raspberry Pi.

Printed at the end of the installer. Starts with https://.

Shown once when the installer ran. Lost it? On the Pi run sudo pi-nas-token add my-laptop for a new one.

This extension's ID

Paste this into PI_NAS_ALLOWED_EXTENSION_IDS in /etc/pi-nas/config.env to allow only this extension to call your server, then sudo systemctl restart pi-nas.
