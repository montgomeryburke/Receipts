Accuracy & safety

Everything the AI writes is checked a second way. Free checks run on this computer: every quote must really be in the file it cites, every number in a draft must be in the email or the sources, and (with "Gemini, checked by the free one") two transcriptions must hear the same numbers. An AI also checks the AI's work: with both a Claude and a Gemini key, each checks the other; with one key, the same AI does a second, separate review (a fresh call that sees only the sources and the result).

The kill switch: cancels every Claude and Gemini call in progress (drafts, chat, meeting prompts, Gemini transcription) and makes no new ones until you resume. The same button is in the side panel and the meeting window.

About you

Standing instructions

Things you told the assistant to always (or never) do. The chat adds them when you ask; you can also add one here. Each is added to the prompts it applies to, so keep them short.

NAS connection

Project folders

Your project folders are the mirrors you keep in NAS files: each one is copied from this computer to the NAS (only changes are sent) and indexed here, on this computer. Email drafts, meeting prompts and the chat all search that one index — there is no second copy.

Folders that are only on the NAS

For files you don't keep on this computer — for example the standards (S6, TAC, MoTI) copied from Google Drive into /Standards. The HP reads them (text and OCR) and they become searchable here. One NAS path per line.

Automate bridge folder

Bridge folder (optional)
A OneDrive-synced folder your Power Automate flows watch (see Power Automate below). Separate from the NAS mirror.

Indexing

Indexing runs on this computer and costs no AI tokens. Only short excerpts of the best-matching files are ever sent to the AI.

Meetings

The meeting window listens to the Teams meeting and your microphone, transcribes, and shows prompts of what to say with quotes from your project files and standards. Transcripts are saved to the NAS.

Free transcription model

Downloaded once (about 80 MB for base.en) and kept in this browser. If this computer can't reach huggingface.co, run the HP setup script with --whisper-model and set "Download from" to your NAS address.

Power Automate

Easiest: describe the job in the side panel's Chat ("set up a flow that logs every email to my tracker") and it walks you through Power Automate step by step, adds the action here, and tests it.

Each flow below becomes an action the assistant can run. Read actions fetch data (an SAP report, a row from a SharePoint Excel tracker); the AI can ask for them while drafting. Write actions change records (add a tracker row, file to GCdocs) and always wait for your click unless you tick "run after every draft".

How to connect a flow
  1. HTTP (premium trigger): create a flow starting with When an HTTP request is received, finish it with a Response action returning JSON {"ok": true, "data": …, "message": "…"}, and paste the trigger URL here.
  2. Bridge folder (standard connectors only): choose a OneDrive-synced folder above. The assistant writes requests/<id>.json; a flow with When a file is created (OneDrive for Business) reads it, does the work, and creates responses/<id>.json with the same JSON shape.
  3. The request the assistant sends: {"requestId","action","kind","params":{…},"item":{"subject","from","project","summary","status"}}. Ask the chat for the exact schema of any action.
