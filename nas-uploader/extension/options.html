Power Automate

Each flow below becomes an action MailMirror can run. Read actions fetch data (an SAP report, a row from a SharePoint Excel tracker); the AI can ask for them while drafting. Write actions change records (add a tracker row, file to GCdocs) and always wait for your click unless you tick "run after every draft".

How to connect a flow
  1. HTTP (premium trigger): create a flow starting with When an HTTP request is received, finish it with a Response action returning JSON {"ok": true, "data": …, "message": "…"}, and paste the trigger URL here.
  2. Bridge folder (standard connectors only): choose a OneDrive-synced folder above. MailMirror writes requests/<id>.json; a flow with When a file is created (OneDrive for Business) reads it, does the work, and creates responses/<id>.json with the same JSON shape.
  3. The request MailMirror sends: {"requestId","action","kind","params":{…},"item":{"subject","from","project","summary","status"}}. See docs/power-automate.md for step-by-step flows for SAP, the Excel tracker and GCdocs.
