    Programs outside Chrome — Power Automate desktop flows
    
A Chrome extension can't click or type in other programs. Power Automate for desktop can (it comes with Windows 11; running flows from a link needs a Power Automate Premium licence). Build the flow there, copy its Run URL from the flow's properties, and add it here. The agent can then start it — you confirm each time.

    

    

      

        
        
      

      
      
      

    

  


  

    What it can and can't do
    
    
      
  • Reads pages, clicks, types, picks from lists, scrolls, presses keys (also held keys for games), works across tabs, opens sites.
    • 
      
  • Files: from the NAS (nas:/…) or your project folders here (local:…) into upload fields, with new names; copies or renames files on the NAS; saves to Downloads.
    • 
      
  • No FTP: Chrome removed it. Use the NAS, or the site's web upload page.
    • 
      
  • It never types passwords or card numbers — it asks you to type them yourself.
    • 
      
  • Risky steps wait for your OK. Page text can't give it orders. ■ Stop, ⏹ Stop AI, or Cancel on Chrome's "debugging this browser" bar stop it at once.
    • 
      
  • A second check looks at a filled form before it is sent and at the result at the end: the other AI with both a Claude and a Gemini key, or a second, separate review by the same AI with one key.
